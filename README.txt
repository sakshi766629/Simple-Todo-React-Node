# Simple Todo App (React.js + Node.js)

## Features
- Add a task
- Mark a task complete/incomplete (click the task)
- Delete a task

## Requirements
Install Node.js on your computer.

## Run the backend
1. Open this project folder in VS Code.
2. Open a terminal and run:
   cd server
   npm install
   npm start
3. Keep this terminal running.

## Run the frontend
1. Open a second terminal.
2. Run:
   cd client
   npm install
   npm run dev
3. Open the URL shown by Vite (usually http://localhost:5173).

Note: This beginner practical stores tasks in server memory. Tasks reset when the backend restarts; no database is needed.
